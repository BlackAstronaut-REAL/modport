# MojModelBridge v3.4 Beta 11

- Normalize vanilla MCreator texture references (`minecraft:block/foo` -> `minecraft:foo`) in element fields.
- Normalize Java recipe references (`Items.ITEMS.X` / `Blocks.BLOCKS.X`) to valid MCreator refs.
- Add generic entity-specific `getTexture()` instanceof branch resolution for shared renderers (moths/butterflies and similar subclasses).
- Reuse the mob's existing spawn egg via `definition.spawnEggTexture` when a matching `egg<entity>` texture exists; do not create separate egg items.
- Improve bow/ranged detection by leaving projectile unset until source projectile binding, avoiding the invalid generic `Arrow` assumption.
- Preserve fishing-rod tool type detection through source superclass/usage evidence.
- Broaden explicit clean-source weapon/tool damage recovery so converter is less likely to fall back to baselines.
- Keep all prior ore-only worldgen, custom block model, animation, armor, food, crafted-procedure and source-fidelity fixes.
