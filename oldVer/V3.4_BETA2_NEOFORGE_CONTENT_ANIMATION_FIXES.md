# MojModelBridge v3.4 Beta 2 — NeoForge 1.21.1 Content/Animation Fixes

This build incorporates fixes validated against the supplied MCreator 2026.2 NeoForge 1.21.1 example workspace and the clean Chaos Persists 1.20.1 source.

## Animation
- Neutral baked previews no longer force wing parts into activity/attack ternary branches.
- Source bind pose remains the additive zero for position/rotation animation channels.
- Loop-period selection now probes source fundamental periods and small integer multiples, preferring the shortest candidate whose sampled endpoint actually closes.
- Loop clips close on the first moving sample rather than snapping back to the static bind pose.
- Existing wing-only geometric continuity is preserved; tails, heads, jaws, necks, arms, and legs are not globally continuity-corrected.
- Walk/idle plus `anim1`, `anim2`, ... fallback recovery remains enabled when conventional names cannot be recovered.

## Blocks/plants
- `cube_all` -> MCreator render type 11 / `Single texture`.
- `cube` -> render type 10 / `Normal` with per-face textures.
- Cross/crop-style plant models -> render type 12 / `Cross model`.
- Grass blocks use render type 14 / `Grass block`.
- Imported block/plant inventory texture fields are left empty so MCreator derives inventory rendering from the block model instead of looking for `assets/<modid>/textures/item/...` files.
- Source model texture references are materialized under the workspace block texture directory.

## Held/custom item models
- Generated NeoForge 1.21.1 custom item models use `neoforge:separate_transforms` like the supplied working workspace.
- Generated custom Blockbench models use the empty texture slot (`""`) and format version `1.21.11`, matching the working example's model structure.
- Held-model texture sidecars use the same empty slot mapping.

## Recipes
- Clean Chaos Persists Java recipe registrations are parsed into native MCreator recipe elements.
- The current clean source produces 218 recoverable recipe elements in the targeted content export.

## Workspace organization
- Dimensions -> `World Generation/Dimensions`
- Biomes -> `World Generation/Biomes`
- Both are nested under the imported mod's top-level folder.

## Validation
- Python regression suite: 70 passed.
- Targeted Chaos Persists content export: 760 elements generated: 377 items, 218 recipes, 71 blocks, 52 tools, 16 plants, 14 armor, 6 biomes, 6 dimensions.
- Held-model exports in targeted run: 8.
