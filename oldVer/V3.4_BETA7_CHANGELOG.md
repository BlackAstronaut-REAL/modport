# MojModelBridge v3.4.0 Beta 7

## Critical worldgen fix

- Final worldgen cleanup no longer relies solely on the inferred source mod ID.
- Every non-target namespace under `src/main/resources/data` is scanned for worldgen registries.
- Non-target `worldgen/configured_feature`, `worldgen/placed_feature`, biome, dimension, structure, structure-set, template-pool, processor-list, position-rule, jigsaw, and biome-modifier resources are removed.
- This specifically eliminates stale source namespaces such as `chaospersists` that can otherwise produce NeoForge `Unbound values in registry ... placed_feature` errors.
- Target-namespace ore configured/placed features remain subject to the ore-only validator and are retained only when they form valid `minecraft:ore` pairs.
- Added a regression test with a rogue `chaospersists` namespace and a valid target ore pair.
