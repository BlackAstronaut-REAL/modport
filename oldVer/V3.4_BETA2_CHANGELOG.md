# MojModelBridge v3.4.0 Beta 2 Changelog

## Fidelity release

This release addresses the first desktop-test feedback after Beta 3/3.1. It concentrates on original-mod accuracy rather than adding broad new content categories.

### Input and full-port workflow

- Added separate compiled and decompiled roots to CLI and GUI.
- Added `full_port_combined.bat`.
- Merged both roots into one graph, resource index, model set, and MCreator workspace.
- Preserved backwards-compatible one-root conversion.

### Model extraction

- Added full decompiled legacy `ModelRenderer`/`ModelBox` support to standalone and MCreator paths.
- Added MCP/SRG `addBox` overload handling.
- Passed renderer constructor arguments into Java model constructors.
- Fixed compiled constructor JVM-stack contamination from unhandled superclass/helper calls.
- Recovered current ModelRenderer position/rotation values during bytecode arithmetic.
- Recovered decompiler alias adjustments such as `var10000.field_78797_d += value`.
- Fixed source-only animation animators overwriting one another before UUID assignment.
- Verified all 109 concrete OreSpawn models and 3,584 cubes match between compiled and decompiled recovery.

### Equipment

- Split durability, use duration, attack bonus, and explicit entity damage.
- Added 1.7 source and bytecode recovery for tool and armor material tables.
- Recovered harvest level, max uses, efficiency, damage, enchantability, armor durability, and per-piece protection.

### Language and descriptions

- Expanded `.lang` / `en_us.json` lookup across all configured roots.
- Applied translations to entities, content, armor pieces, and custom tabs.
- Recovered literal tooltip strings and language-file descriptions into MCreator special information.

### Armor textures

- Added legacy `<material>_1/_2` armor-layer recognition and MCreator-compatible renaming.
- Separated layer matching from inventory-icon matching.
- Resolved each armor piece icon independently.
- Tightened matching to avoid item/entity texture cross-contamination.

### Held Tool 3D Models

- Preserved 1.8–1.12 item JSON `display` transforms.
- Added legacy `IItemRenderer` linkage and GL transform extraction.
- Converted held legacy models into MCreator custom Tool 3D Models while retaining the inventory icon.

### Animations

- Closed looping endpoints to the initial pose.
- Preserved multiple source-only bone animators.
- Improved helper/branch recovery and position channels.

### Texture identity

- Removed shared-prefix matching behavior that could assign one texture to many similarly prefixed classes.

## Beta 2 follow-up fixes

- Extended legacy `IItemRenderer` recovery to compiled-only input.
- Compiled-only bytecode now discovers arbitrary renderer registration classes instead of relying on registry-source naming conventions.
- Follows static item fields from `registerItemRenderer` to the renderer class and then to the referenced legacy model and texture.
- Added regression fixtures for compiled-only OreSpawn Bertha, Slice, and Royal renderer recovery.
- Automated regression suite now reports 45 passing tests.

## Tests

- 45 portable automated tests pass.
- Added regressions for dual roots, source-only models, Java animation UUIDs, loop closure, equipment bytecode, armor layers/icons, language descriptions, held-model transforms, constructor aliases, and compiled position arithmetic.
