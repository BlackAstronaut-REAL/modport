# MojModelBridge v3.4.0 Beta 12 — Reconstructed from Beta 11

This release reconstructs the missing Beta 12 state from the surviving Beta 11 package and applies the complete source-fidelity pass requested after Beta 11.

## Source/MCreator fidelity
- Normalizes vanilla MCreator block texture references (`minecraft:oak_log`) while preserving raw Mojmap model references (`minecraft:block/oak_log`).
- Normalizes Java recipe references (`Items.ITEMS.X` -> `Items.X`, `Blocks.BLOCKS.X` -> `Blocks.X`) without synthetic `#0` suffixes.
- Keeps custom stateful block models/blockstates authoritative after all element generation.
- Recovers source-authored food properties, tool/weapon durability/damage/efficiency/enchantability, and crafted enchantment procedures.
- Adds source-backed custom spawn-egg textures through `livingentity.definition.spawnEggTexture` and suppresses duplicate `egg<entity>` item elements when a matching entity exists.
- Creates a single mod-name creative tab and assigns imported items, tools, armor, blocks, plants, and living entities to it.

## Ranged items
- Custom source classes using `UseAnim.BOW` are emitted as native MCreator Item elements with ranged fields.
- FishingRodItem subclasses remain native Fishing Rod tools.
- Source projectile bindings are recovered where the clean source explicitly constructs the projectile class.

## Animation fidelity
- Separates idle and walking sampling clocks so age-based idle motion no longer contaminates walking clips.
- Recovers exact common loop periods from source trig frequencies instead of defaulting unrelated clips to one second.
- Closes animation seams to the first moving sample.
- Preserves activity/open branches for source-gated animation groups; wing membrane counterparts (`mem*`, `rmem*`) are treated consistently with wing bones.
- Retains render multiplicity and runtime-rotation metadata for repeated models such as Rotator.

## World generation
- Biomes, dimensions, villages, structures, template pools, processor lists, and non-ore worldgen remain disabled by policy.
- Ore generation is retained from exact configured/placed feature data, including vein size (`frequencyOnChunk`), occurrences per chunk (`frequencyPerChunks`), height range, uniform/triangle generation shape, and strict stone/deepslate replacement.
- Final worldgen cleanup removes stale source namespaces and orphaned placed-feature registries.

## Validation
- Focused Beta 12 regression suite: 12/12 passing.
- Full source model scan successfully discovered the clean Chaos Persists corpus and recovered 136 renderer links / 109 Java model sources before the environment execution window expired during the long end-to-end export.
